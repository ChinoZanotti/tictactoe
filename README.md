# Tic Tac Toe - React

This project is a classic **Tic Tac Toe game** built by following the official [React documentation](https://react.dev/).  
The main purpose of this repository is to **learn the fundamentals of React**: components, props, state, and conditional rendering.

---

## 🎮 Features

- Interactive Tic Tac Toe gameplay.
- Turn tracking between two players.
- Winner and draw detection.
- Ability to restart the game.

---

## 🚀 Technologies Used

- [React](https://react.dev/)  
- JavaScript (ES6+)  
- HTML5  
- CSS3
